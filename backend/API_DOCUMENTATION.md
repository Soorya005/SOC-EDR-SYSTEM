# SOC-EDR Backend API Documentation

## Overview

This document describes the REST API implemented for the SOC-EDR backend.

The backend is built using **FastAPI** and **SQLite** and exposes APIs for:

- Event Management
- Alert Management
- Dashboard Statistics

Base URL

```
http://127.0.0.1:8000
```

Swagger UI

```
http://127.0.0.1:8000/docs
```

---

# Events API

Events represent normalized Sysmon events collected from monitored endpoints.

---

## 1. Create Event

**Endpoint**

```
POST /events/
```

### Request

```json
{
  "event_id": 1,
  "host": "DESKTOP-01",
  "process_name": "powershell.exe",
  "parent_process": "WINWORD.EXE",
  "command_line": "powershell.exe -EncodedCommand ..."
}
```

### Success Response

```json
{
    "message":"Event created successfully",
    "event_id":"<UUID>"
}
```

---

## 2. Get All Events

**Endpoint**

```
GET /events/
```

### Response

```json
[
    {
        "id":"...",
        "event_id":1,
        "host":"DESKTOP-01",
        "process_name":"powershell.exe",
        "parent_process":"WINWORD.EXE",
        "command_line":"powershell.exe -EncodedCommand ...",
        "raw_json":"...",
        "created_at":"..."
    }
]
```

---

## 3. Get Event by ID

**Endpoint**

```
GET /events/{event_id}
```

Returns a single event.

---

## 4. Delete Event

**Endpoint**

```
DELETE /events/{event_id}
```

Deletes the event.

**Note**

Deleting an event automatically deletes all alerts associated with that event using SQLite **ON DELETE CASCADE**.

# Alerts API

Alerts are generated by the Detection Engine (Sigma Rules).

One event can generate multiple alerts.

---

## 1. Create Alert

**Endpoint**

```
POST /alerts/
```

### Request

```json
{
  "rule_name":"Encoded PowerShell",
  "severity":"High",
  "event_id":"<EVENT_UUID>",
  "technique_id":"T1059.001"
}
```

### Success Response

```json
{
    "message":"Alert created successfully",
    "alert_id":"<UUID>"
}
```

---

## 2. Get All Alerts

**Endpoint**

```
GET /alerts/
```

Optional query parameters

```
status
severity
```

Example

```
GET /alerts?status=New

GET /alerts?severity=Critical
```

---

## 3. Get Alert by ID

**Endpoint**

```
GET /alerts/{alert_id}
```

Returns one alert.

---

## 4. Update Alert Status

Used by SOC analysts.

**Endpoint**

```
PATCH /alerts/{alert_id}/status
```

### Request

```json
{
    "status":"Investigating"
}
```

Possible values

- New
- Investigating
- Escalated
- Closed
- False Positive

---

## 5. Update AI Analysis

Used after AI analysis is completed.

**Endpoint**

```
PATCH /alerts/{alert_id}/ai
```

### Request

```json
{
    "ai_explanation":"Encoded PowerShell execution detected.",
    "ai_recommendations":"Decode the command and inspect parent process."
}
```

---

## 6. Delete Alert

**Endpoint**

```
DELETE /alerts/{alert_id}
```

Deletes an alert.

---

# Dashboard Statistics API

Used by the Dashboard.

---

## 1. Summary Statistics

**Endpoint**

```
GET /stats/summary
```

### Response

```json
{
    "total_alerts":12,
    "critical_alerts":3,
    "open_alerts":8
}
```

---

## 2. Alert Trends

Returns daily alert counts.

**Endpoint**

```
GET /stats/trends
```

### Response

```json
[
    {
        "date":"2026-07-03",
        "count":5
    }
]
```

---

## 3. MITRE Technique Heatmap

Returns alert counts grouped by MITRE ATT&CK Technique ID.

**Endpoint**

```
GET /stats/heatmap
```

### Response

```json
[
    {
        "technique_id":"T1059.001",
        "count":7
    }
]
```

# Alert Lifecycle

The backend follows the workflow below.

```
Sysmon Event
        │
        ▼
Create Event

        │
        ▼
Detection Engine

        │
        ▼
Create Alert

        │
        ▼
SOC Analyst

Update Status

        │
        ▼
AI Analysis

Update Explanation

        │
        ▼
Incident Investigation
```

---

# Database Relationships

```
Events
    │
    │ 1
    │
    ├──────────────∞
                   │
                Alerts
```

- One Event can generate multiple Alerts.
- Every Alert belongs to exactly one Event.
- Deleting an Event automatically deletes all related Alerts.
